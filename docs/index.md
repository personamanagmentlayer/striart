# Striart

Multi-agent Git orchestrator for AI coding agents: each agent works in its
own full Git clone, a Router predicts the files a task will touch and
serializes colliding tasks, and every merge goes through a semantic merge
step and a blocking Test Gate before it lands on the target branch.

This site publishes the documentation tree from the
[striart](https://github.com/personamanagmentlayer/striart) repository.
The repository's own README is the showcase (English by default, with a
French version); everything below is the detail.
